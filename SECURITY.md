# Security Policy

## Supported versions

This project has not published a release yet. Security fixes are made on the default branch during pre-release development. After releases begin, this table will be updated with the actually supported versions; no support for an unpublished or older version is implied.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting form:

https://github.com/genm/raycast-qr-scanner/security/advisories/new

Include the affected commit or version, macOS and Raycast versions, reproduction steps, impact, and any suggested mitigation. Do not include real secrets, private QR payloads, or unrelated personal data.

The maintainer will acknowledge and triage reports as capacity allows. This project does not promise a response or remediation deadline. Coordinated disclosure timing and credit will be agreed with the reporter when a report is validated.

Before making the repository public, the maintainer must enable and verify GitHub private vulnerability reporting. If the form is unavailable, publication readiness is blocked until another working private contact is documented.
