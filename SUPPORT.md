# Support

This is a community-maintained pre-release project with no guaranteed response time or compatibility SLA.

- For reproducible bugs, use the repository's bug report form.
- For scoped enhancements, use the feature request form.
- For development and contribution questions, start with [README.md](README.md) and [CONTRIBUTING.md](CONTRIBUTING.md), then open a discussion or issue if the public repository has that surface enabled.
- For vulnerabilities, use the private route in [SECURITY.md](SECURITY.md).
- For Raycast platform or API problems unrelated to this extension, use Raycast's official support and developer channels.

For camera, permission, result-display, and concurrent-build failures, follow [docs/troubleshooting.md](docs/troubleshooting.md) before opening an issue. Include which command failed, the machine-readable test result when applicable, and privacy-safe diagnostics only.

Before sharing diagnostics, remove QR content, Wi-Fi passwords, clipboard data, desktop screenshots, usernames, paths, and other personal or confidential information.
